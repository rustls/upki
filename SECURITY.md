# Security Policy

Before reporting a security bug, make sure to consider whether the finding
exists under a realistic threat model. Misconfiguration that is unlikely to
happen accidentally is unlikely to be a security bug.

Please report security bugs [via github](https://github.com/rustls/upki/security/advisories/new).
Make sure to disclose any use of AI assistance upfront.

If accepted, we'll then:

- Prepare a fix and regression tests.
- Submit an advisory to [rustsec/advisory-db](https://github.com/RustSec/advisory-db).
- Refer to the advisory in relevant release notes.
